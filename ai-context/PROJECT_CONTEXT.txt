7. KEY TECHNICAL PATTERNS (critical — always follow these)
================================================================================

REACT UI (ui-react):
  Axios baseURL = "/" (proxied to api-gateway by Vite)
  Interceptor 1: injects Authorization: Bearer from localStorage access_token
  Interceptor 2: unwraps { success, data } envelope → exposes just data
  Interceptor 3: 401 → clear localStorage → redirect to /login
  All API calls through src/api/client.ts named modules (authApi, libraryApi, etc.)
  Error parsing: parseApiError() normalises all error shapes to a user-facing string
  No business logic in frontend — backend-first with compatibility fallback pattern:
    if (backendData?.backend_rules?.risk_score !== undefined) use it; else compute locally

BACKEND-FIRST WITH FALLBACK (migration pattern):
  Backend returns additive enriched fields; UI prefers them but falls back to
  locally computable values. This allows phased backend migration without UI breakage.
  Fields: backend_rules, business_critical, confidence_score, confidence_band,
          priority_counts, risk_score, sla_forecast, pie_distribution, etc.

PER-BUTTON INLINE LOADERS (React):
  Use TanStack Query mutation isPending per button action (NOT a page-level spinner).
  Applied on: scheduler retry actions, settings per-key save, library bulk-fetch/sync,
  user create/deactivate/reactivate.

GLOBAL ASYNC LOADER:
  GlobalAsyncLoader component mounted in Layout.tsx.
  Shows delayed global loading indicator with min-visible anti-flicker behavior.
  Only activates for slow queries/mutations; does not replace per-button loaders.

WEEKLY DIGEST:
  businessApi.weeklyDigest → GET /api/v1/business/weekly-digest
  Fully backend-computed. No mock fallback object.
  UI shows loading / error / empty state with retry button.

IMPORTS (ALL Streamlit UI pages):
  Use ABSOLUTE imports only:  from src.X import Y
  NOT relative: from ..X import Y  (Streamlit runner breaks relative imports)

MODULE ALIASING (Streamlit, avoid shadowing config.settings):
  from src.pages import settings as settings_page
  from src.pages import teams as teams_page

SCHEDULE FIELD NAME:
  PUT /api/v1/schedule → body field = "cron"  (NOT "cron_expression")

LIBRARY API — data is nested (Streamlit client):
  libs = resp.get("data", {}).get("libraries", [])   # data.libraries

RECOMMENDATIONS API — data is a LIST directly (Streamlit):
  recs = resp.get("data") or []    # NOT data.get("recommendations")

LIFECYCLE COMPLETE auto-effects:
  → library.current_version = completed_version
  → library.update_needed = "none"
  → writes library_update_log entry (type="lifecycle_complete")

HEALTH ENDPOINT returns LIST not dict:
  services = resp.get("services", [])    # NOT .values()

CASCADE DELETE (deleting a library removes):
  version_history, recommendations, external_sources, update_logs (audit),
  upgrade_lifecycle, scrape_caches, cve_caches, ownerships

UI — NO HTML in Streamlit tabs:
  st.markdown(html, unsafe_allow_html=True) DOES NOT render inside st.tabs()
  Use native: st.success/error/warning/info/metric/container(border=True)

LLM USAGE LOGGING:
  After each LLM call → recommendation-service fires background POST /api/v1/llm/log
  Cost auto-calculated in llm_analytics.py pricing table

9. SETUP & OPERATIONS (setup.sh + manage.sh)
================================================================================

setup.sh — One-shot bootstrap (enhanced 2026-07-01):
  ./setup.sh                                        # full setup + start all
  ./setup.sh --no-start                             # setup only, don't start
  ./setup.sh --reset                                # drop DB + re-setup
  ./setup.sh --service api-gateway                  # setup one service
  ./setup.sh --service lib-data-service,scheduler   # setup selected services
  ./setup.sh --service ui-react --force-deps        # force npm reinstall
  ./setup.sh --help                                 # show usage

  Dependency install optimizations:
  - Python: skips pip install when combined_requirements.sha256 hash unchanged
  - Node: skips npm install when package.json/package-lock.json hash unchanged
  - Uses npm ci when package-lock.json exists; npm install otherwise
  - --force-deps bypasses hash checks

manage.sh — Service lifecycle (9 services):
  bash manage.sh start                     # start all 9 services
  bash manage.sh start api-gateway         # start one
  bash manage.sh stop  scheduler-service   # stop one
  bash manage.sh restart ui-react          # restart one
  bash manage.sh restart all               # rolling restart
  bash manage.sh status                    # live status table
  bash manage.sh logs  scraper-service     # tail log
  bash manage.sh health                    # ping all /health endpoints

  Known service names (must match exactly):
  api-gateway, library-data-service, scraper-service, comparison-service,
  recommendation-service, notification-service, scheduler-service,
  ui-service, ui-react
